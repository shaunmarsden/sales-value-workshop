# Calderwick Value Workshop Output

> This is a fictional example. Calderwick, the people and the figures are invented. I wrote it to show the method with an existing customer. It isn't a logged run.

## The Work Today

Calderwick Housing Association manages about 3,000 homes. Tenancy officers visit tenants and write up each visit by hand afterwards. Rhian Ashworth, Head of Tenancy Services, says the write-ups are often late and some are thin.

Calderwick is an existing customer. It already pays for 15 seats of an AI-assisted writing tool from the seller, and its officers use it mostly for emails. The seller's account manager came to the workshop expecting that Rhian might ask for more seats.

The group did not claim how long a write-up takes. Nobody had timed one.

## Why It Matters

- A late write-up can mean the next officer on a case doesn't know what was agreed.
- A thin write-up makes a complaint or a review harder to answer, but nobody has counted how often that happens.
- Rhian says officers put the work off. She hasn't measured it.

## Better Looks Like

Rhian said a useful improvement would mean:

1. an officer can turn rough visit notes into a first-draft write-up in Calderwick's standard layout;
2. the officer checks and edits every write-up before it is saved; and
3. a team leader can see that write-ups are finished within two working days without chasing anyone.

The first measure is minutes spent per write-up on a sample of visits. The second is the share of sample write-ups that pass a team leader's checklist. Neither measure has a baseline yet.

## First Test

| Item | Agreed fictional test |
| --- | --- |
| Scope | Three officers, two weeks, up to five visits each |
| Tool | The 15 seats Calderwick already pays for. No new seats, module or price |
| Information | Invented visit notes only. Calderwick's data protection officer approved the tool for emails, not for tenant details |
| Output | A draft write-up in the standard layout |
| Human check | The officer checks every draft before use. A team leader checks a sample against the checklist |
| Review | Rhian and one team leader compare time and quality after two weeks |

The account manager didn't propose more seats. The test uses what Calderwick already pays for, so there is nothing to approve and nothing to sell. The [Value Evidence Check](../methods/value-evidence-check.md)'s Test row asks for a first step that is small, safe and reviewable, and this one is.

## Decision

Calderwick agreed to run the two-week test with invented visit notes and the seats it already has. The account manager did not ask for more seats, a new module or a change to the contract.

If the tool can't produce the standard layout, the honest answer is that it doesn't fit this job, and the account manager will say so. Rhian will ask the data protection officer whether real visit notes could ever be used. Nobody will use them before that answer.

## What Remains Unknown

- Whether the tool Calderwick has can produce the standard layout well enough, or at all
- Whether the data protection officer would ever allow real visit notes
- Whether write-up time is the real problem, or whether the visits themselves are
- Whether a time saving would matter enough to change how officers work
