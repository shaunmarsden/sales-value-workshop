# Roadmap

## Next Cases

- An existing customer trying to improve a process without buying a new tool
- Add a manual path to the Wrenfield example that measures the starting point without any tool. When I tested the method live on a new scenario with a procurement gate, it found this path by itself: gather timing and bounce-back data by hand while the governance approval goes ahead separately. Wrenfield's current write-up doesn't show it

## Next Tools

- A one page printable canvas
- A facilitator note for difficult value conversations
- A simple anonymised format for findings

## Only After Real Use

- A calculator for clearly defined, customer supplied inputs
- An interactive workshop board
- Industry specific routes

I want to improve the workshop when real use shows a need, not add features because they sound impressive.

## Built So Far

- A first case that reaches an agreed test, with a real measure and no invented saving
- A mid market case with no agreed owner, which correctly ends in "not yet" rather than making up a test
- An enterprise case with a clear owner, problem and measure. It correctly ends in "not yet" for a different reason: the security and procurement approval hasn't started, rather than evidence being missing. On 5 August 2026 I tested the method itself, not just this write-up, on a new scenario with the same gate. The gate came up because the guide's own test rule says "approved information only", not because of any extra digging the guide doesn't ask for. This was one internal test, not independent evidence
