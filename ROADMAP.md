- Add a parallel manual, no-tool baseline path to the Wrenfield example. A live test of the method against a fresh procurement-gated scenario found this on its own, gathering timing and bounce-back data by hand while a governance approval is separately sought, and Wrenfield's current write-up does not show it

## Next Tools

- A one page printable canvas
- A facilitator note for difficult value conversations
- A lightweight anonymised findings format

## Only After Real Use

- A calculator for clearly defined, customer supplied inputs
- An interactive workshop board
- Industry specific routes

The point is to improve the workshop when real use exposes a need, not to add features because they sound impressive.

## Built So Far

- A first case reaching an agreed test, with a genuine measure and no invented saving
- A mid market case with no agreed owner, correctly ending in "not yet" rather than manufacturing a test
- An enterprise case with a clear owner, problem and measure, correctly ending in "not yet" for a different reason: an unstarted security and procurement approval, not missing evidence. The underlying method, not just this written example, was tested on 5 August 2026 against a fresh scenario with the same gate. Following the guide's own "approved information only" test criterion is what led to the gate surfacing, not any extra probing beyond what the guide already asks for. One internal test, not independent evidence
